(April 7, 2026)

The website has finally fully launched, with a custom domain name, https, all that good stuff (thanks Github Pages!).

The primary function of this website was not intended to be a drawings compilation - in fact, it was never intended to go public in the first place - but halfway through development, I thought it a good idea to add them. After all, like it or not, the 'Drawing Badly' thing WAS over two years of my life, so it seems wasteful to not at least feature it. Then I realised there wouldn't be a whole lot of point in keeping this private if I want it to house all my drawings, so... we've ended up here. Eventually, the bad drawings did end up becoming priority number one though and also ended up taking the most work to pull off.

Actually trying to include it and make it work in a way that didn't involve copy-paste static html was certainly an interesting experience and something I didn't expect to be quite as much of a pain as it turned out to be. But hey, I got it done in the end. Must count for something.

This website is obviously nothing amazing, but for a first (proper) attempt, I'm quite pleased with how it turned out. HTML, JavaScript, CSS - all done completely from the ground up... and a lot of tutorials. Enjoy! (Don't look at the code, you will have an aneurysm).

I ought to add that for a large majority of the drawings, I no longer have the original versions (I was running out of storage space). This means they're not as high quality as I'd like, hence I've provided links to their respective Reddit posts in the image notes, which should look a little nicer than on here.

Oh, and don't worry about the 'Coming Soon' bit, that's in the works but there's a few things I have to get around to first before it.

Anyway, we're here now, and I've delivered a drawing compilation three years too late. Better late than never though, I suppose.
